# 🚨 TrustLink Contract Error Reference

This document provides a comprehensive reference for `ContractError` variants returned by the TrustLink Soroban escrow contracts. When an on-chain interaction fails, the frontend parses the error using `parseContractError` and displays the details below.

## Error Codes Table

| Numeric Code | Name | Meaning | Recommended Resolution |
| :--- | :--- | :--- | :--- |
| **100** | `Unauthorized` | The caller (source account) does not have the required permissions for the method. | Verify that the wallet connected in the app matches the Buyer/Vendor address for this escrow. |
| **101** | `InvalidState` | The escrow is in a lifecycle state that does not permit the requested operation (e.g., shipping before funding). | Check the current status of the escrow. Some actions (like `confirm_delivery`) require the status to be `SHIPPED`. |
| **102** | `InsufficientBalance` | The account does not have enough XLM (for fees) or USDC (for price) to complete the transaction. | Fund the connected wallet with sufficient XLM/USDC and retry. |
| **103** | `AlreadyExists` | An escrow with the provided ID has already been initialized on the network. | Ensure the Escrow ID is unique or wait for the existing escrow to resolve/expire. |
| **104** | `NotFound` | The requested escrow ID could not be located on the blockchain. | Verify the escrow ID in the URL. If recently created, wait a few seconds for ledger finality. |
| **105** | `DisputeActive` | An operation was attempted on an escrow that is currently in a `DISPUTED` state. | No further actions (release/refund) can be taken until the dispute is resolved by an admin. |
| **106** | `Expired` | the shipping window for this escrow has closed without the vendor marking it as shipped. | The escrow is now locked. Funds may need to be reclaimed or a new link generated by the vendor. |
| **107** | `InternalError` | A low-level Soroban host error occurred during contract execution. | This usually indicates a network issue or an unexpected contract state. Retry after a few minutes. |

## Handling Errors in Code

Contract errors are handled in `lib/stellar/contract.ts`. You can use the `parseContractError` utility to extract human-readable messages from caught exceptions.

```typescript
import { parseContractError } from "@/lib/stellar/contract";

try {
  await fundEscrow(...);
} catch (error) {
  const message = parseContractError(error);
  // Returns "Contract Error: Insufficient balance" or similar
}
```
